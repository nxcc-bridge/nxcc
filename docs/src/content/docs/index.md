nXCC is the secure, off-chain orchestration engine that connects any blockchain, API, or system. Build complex, high-performance workflows without the cost and complexity of a new layer.

## Quick Start

New to nXCC? Start with our [Getting Started guide](/docs/guides/getting-started/) to learn the basics.

## Key Features

- **Define Logic, Not Infrastructure**: Define complex, event-driven workflows in JavaScript
- **Compute with Confidence**: Powered by Trusted Execution Environments (TEEs) for verifiable security
- **Decentralize Trust**: Federated trust model with on-chain identity contracts
- **Integrated Secret Management**: Built-in secure key management with TEE-to-TEE protocols
